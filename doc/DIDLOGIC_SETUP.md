# Подключение DIDLogic — настройка и важное ограничение

## 1. Регистрация и получение API-ключа

1. Зарегистрироваться на [didlogic.com](https://didlogic.com/) / [app.didlogic.com](https://app.didlogic.com/).
2. **API доступен только с тарифа Plus и выше.** Если аккаунт создан на тарифе Core — сначала нужно апгрейднуться в личном кабинете.
3. После апгрейда обратиться к своему аккаунт-менеджеру DIDLogic с запросом API-ключа (самостоятельно через UI ключ создать нельзя — это подтверждённый факт из официального FAQ DIDLogic).
4. Вставить ключ в `backend/.env`:
   ```
   DIDLOGIC_API_KEY=ваш_ключ
   ```

## 2. Важная оговорка по этому провайдеру — прочитать перед использованием

У DIDLogic заметно меньше публичной REST-документации по конкретным
эндпоинтам, чем у Telnyx или DIDWW. Реализация в этом проекте
(`backend/src/didlogic/didlogic.client.ts`) опирается на:

- официальный README проекта DIDLogic и открытый исходный код
  community-инструмента `didlogic_mcp` (github.com/UserAd/didlogic_mcp),
  где явно видны реальные вызовы к `GET /v1/balance` и `POST /v2/buy/purchase`;
- предположение о заголовке авторизации `Authorization: Bearer <ключ>` — это
  общепринятое соглашение и косвенно подтверждается тем, что сам MCP-сервер
  ожидает Bearer-токен от своих клиентов, но **это не подтверждено напрямую
  в официальной документации DIDLogic**.

**Перед первым реальным использованием обязательно проверьте первый запрос
(например, `getBalance()`) на тестовом ключе.** Если придёт 401 — скорее
всего дело в формате заголовка авторизации, его нужно будет поправить в
`didlogic.client.ts` по факту (например, на `Api-Token` или query-параметр —
уточнить у поддержки DIDLogic или в личном кабинете рядом с самим ключом).

## 3. Отличие от Telnyx/DIDWW: нет автопоиска номера по стране

**Это ключевой момент.** У Telnyx и DIDWW есть эндпоинт вида "покажи мне
доступные номера в Украине" — можно было автоматически взять первый попавшийся
и купить. У DIDLogic такого публично подтверждённого эндпоинта нет: судя по
документации и открытой реализации, единственный способ купить номер —
`POST /v2/buy/purchase` с уже известным конкретным номером в формате E.164.

Найти сам номер можно только вручную — в личном кабинете DIDLogic → **Buy**,
там доступен поиск по стране и коду города.

**Поэтому в UI кнопка "Добавить номер" при выборе DIDLogic ведёт себя иначе**,
чем для Telnyx/DIDWW: рядом появляется текстовое поле, куда нужно вставить
конкретный номер, скопированный из личного кабинета DIDLogic. Без номера
кнопка неактивна.

## 4. Что происходит при покупке в этом проекте

1. Вводите номер (например `380441234567`) → `POST /v2/buy/purchase`.
2. DIDLogic отвечает **синхронно** (в отличие от DIDWW, где заказ мог быть "Pending") — сразу видно, куплен номер или нет, и его характеристики (канал, стоимость, `require_docs`).
3. Если у номера есть `require_docs` (нужны документы для активации — паспорт/подтверждение адреса и т.д.) — карточка получает статус "Ожидание", пока документы не будут загружены и одобрены в личном кабинете DIDLogic.
4. Если документов не требуется — номер сразу получает статус "Активен".

## 5. КРИТИЧЕСКИ ВАЖНО: DIDLogic тоже не даёт звонить программно

Как и у DIDWW, у DIDLogic нет REST-эндпоинта "позвони на этот номер".
Судя по открытому списку возможностей их API (balance, SIP-аккаунты
"sipfriends", покупка/удаление DID, история звонков/транзакций) — это
провижининг номеров + управление SIP-аккаунтами для их использования через
SIP-трафик, а не программная телефония вроде Telnyx Call Control.

Чтобы реально позвонить с номера DIDLogic, по документации самого DIDLogic
нужно:
1. Создать SIP-аккаунт в личном кабинете (раздел SIP),
2. Настроить исходящий SIP-трафик через свою PBX/SBC (например VitalPBX,
   Asterisk, FreeSWITCH), зарегистрированную на региональный SIP-шлюз
   DIDLogic,
3. Указать купленный номер как Caller ID для этого SIP-аккаунта.

**Поэтому защита в `calls.service.ts` та же, что и для DIDWW**: пробный
звонок с озвучкой ищет активный номер **только с `provider: 'telnyx'`**.
Номера DIDLogic (как и DIDWW) в пуле видны и помечены активными, но кнопка
"Звонок" на вкладке "Озвучка" через них не работает.

### Итог по DIDLogic-номерам сейчас

| Что работает | Что не работает |
|---|---|
| Покупка конкретного номера через API | Автопоиск доступных номеров по стране |
| Отображение в пуле (карточка, статус active/pending) | Исходящий звонок с этого номера через текущий проект |
| Хранение провайдера/ID номера в БД | Проигрывание озвучки на этом номере |
